# وب‌سایت فروشگاهی عطر و ادکلن 🌸💨

یک وب‌سایت فروشگاهی با طراحی مدرن و واکنش‌گرا برای فروش عطر و ادکلن.  
ساخته شده با **HTML**، **Tailwind CSS** و کمی **JavaScript** برای ایجاد تعامل.

## ✨ ویژگی‌ها

- 🎨 طراحی مدرن و مینیمال
- 📱 کاملاً **ریسپانسیو** برای موبایل، تبلت و دسکتاپ
- 🛍️ نمایش محصولات همراه با تصویر، قیمت و جزئیات
- 🚀 تجربه کاربری ساده و روان


## 🛠️ تکنولوژی‌های استفاده‌شده

- **Tailwind CSS** – برای استایل‌دهی سریع و منعطف
- **HTML5** – ساختار تمیز و معنایی
- **JavaScript** – برای ایجاد تعامل‌های ساده
